# Tandem Reach

Marketing website for Tandem Reach, an AI-assisted partner discovery and outreach platform.

## What's inside
- `index.html`: the complete single-page site (styles, script and hero video are embedded), including a login page view at `#/login`.

## Run locally
Open `index.html` in any browser. The login page is at `index.html#/login`.

## Publish with GitHub Pages
1. Go to **Settings > Pages**.
2. Under **Branch**, choose `main` and `/ (root)`, then save.
3. The site will be live at `https://<your-username>.github.io/<repository-name>/` and the login page at `.../#/login`.

## Notes
- The login form is a front-end preview only. It does not store or send credentials. Connect a real authentication service before using it.
- The demo form is a preview and does not send data.
- Privacy, Terms and Contact links are placeholders.
